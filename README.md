## 🎯 About the Project / អំពីគម្រោង

**UNIVERSE HUOKAING THARA Prank Video Platform** is an official entertainment repository designed to deliver joyful and safe comedy content. Engineered with responsive design principles, this platform features 5 curated prank video cards complete with interactive social media feed layouts.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **Responsive Layout:** Built using modern HTML5, CSS3, and modular JavaScript architectures optimized for mobile, tablet, and desktop devices.
* **Dual Language Support:** Fully integrated bilingual content in both **Khmer (ខ្មែរ)** and **English**.
* **Facebook-Style Click-to-Run Autoplay:** Custom interactive overlays on each video wrapper that trigger instant video streaming upon user click.
* **Curated Prank Feed:** Showcases top funny and lighthearted videos designed to bring smiles and laughter
